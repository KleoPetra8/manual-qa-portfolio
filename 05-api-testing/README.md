# API Testing

This section contains API testing examples created in Postman using the JSONPlaceholder REST API.

## Covered HTTP Methods

- GET
- POST
- PUT
- PATCH
- DELETE

## Test Scenarios

- Retrieve an existing user
- Attempt to retrieve a non-existing user
- Create a new user
- Update an existing user
- Partially update an existing user
- Delete a user

## Automated Assertions

Postman scripts are used to validate:

- HTTP status codes
- Response body data
- Response time
- User IDs
- Updated field values
- Empty responses
- Positive and negative API scenarios

## Tools

- Postman
- REST API
- JSONPlaceholder
- JavaScript assertions
