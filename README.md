# Manual QA Portfolio

Hi, I'm Petra. This repository contains practical QA work I've created while developing and refreshing my software testing skills. 

The portfolio focuses mainly on manual testing and includes test planning, test cases, bug reports and regression checklists. I've also included hands-on API testing in Postman and basic SQL queries used for data validation and QA investigation.

## What I've worked with

- Manual testing
- Test case design
- Bug reporting
- Regression testing and checklists
- API testing with Postman
- Basic API assertions in Postman
- SQL for data validation
- Git and GitHub

## Portfolio contents

### [01 — Test Plan](./01-test-plan)
A test plan for the ShopEasy e-commerce application, covering scope, testing approach, test environment, entry and exit criteria, and identified risks.

### [02 — Test Cases](./02-test-cases)
Manual test cases covering key e-commerce functionality, including registration and other user flows.

### [03 — Bug Reports](./03-bug-reports)
Bug reports written during exploratory testing, with reproduction steps, expected and actual results, severity and priority.

### [04 — Checklists](./04-checklists)
A regression testing checklist covering the main areas of an e-commerce application.

### [05 — API Testing](./05-api-testing)
A Postman collection covering GET, POST, PUT, PATCH and DELETE requests. It includes positive and negative scenarios and basic automated assertions for status codes, response data and response time.

### [06 — SQL Testing](./06-sql-testing)
SQL query examples for data validation and QA investigation, including filtering, sorting, NULL checks, counting records and basic JOIN queries.
